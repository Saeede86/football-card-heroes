# Football Card Heroes ⚽🃏

بازی کارت فوتبالی امیرعلی! بسته باز کن، کارت جمع کن و تیمت رو بساز.

## چطور بازی رو باز کنم؟
فایل `index.html` رو توی مرورگر باز کن.

## فایل‌های بازی
- `index.html` → اسکلت صفحه (چه چیزهایی توی صفحه هست)
- `style.css` → ظاهر و رنگ‌ها
- `cards.js` → لیست همه کارت‌ها (برای اضافه کردن کارت جدید اینجا رو عوض کن)
- `game.js` → مغز بازی (سکه‌ها، ذخیره کردن، نشون دادن کارت‌ها)
- `pack.js` → باز کردن بسته (قیمت بسته و شانس کارت‌ها اینجاست)
- `penalty.js` → مینی‌گیم پنالتی (سکه هر گل و شانس دروازه‌بان اینجاست)
